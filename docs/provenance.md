# 公開版の来歴

`taskflow`の`worker/src/v1/`から、TaskService、契約定義、DB層、担当者の検査、繰り返しタスクの処理、通知用の型を抽出しました。
これらのソースは変更していません。
抽出時のGit treeとファイル単位のハッシュは[source-manifest.json](source-manifest.json)に記載しています。

テスト用のSQLiteD1アダプター、関連マイグレーション、タスクのテストも引き継いでいます。
AI作業のテストからは、公開版に含めない旧画面との互換性テストを1件取り除きました。
ルーターとOAuthのテストは対象外です。
公開用に追加した画面とサーバーは`demo/`に分けています。

`tasks/wake.ts`は型の参照先として残しています。
デモではAgentWakeを生成せず、Webhookや外部AIを呼び出しません。
マイグレーションはスキーマ定義だけを使用し、運用DBをコピーしていません。

履歴、デプロイ設定、OAuth設定、運用記録は新規リポジトリへ持ち込んでいません。
依存パッケージのライセンスは各パッケージに従います。
